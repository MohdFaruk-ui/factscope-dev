Privacy policy

My Automation Agent · last updated 21 November 2026

My Automation Agent is a small program I run on my own computer to manage my own YouTube channels, FactScope and Prompt Tadka. Nobody else uses it. This page explains, as plainly as I can, what it can see in a Google account and what it does with it.

What it asks Google for

  • Upload videos (YouTube, upload): to put my finished videos on my channel, set to private with a publish time, with the thumbnail I made.
  • Read my channel (YouTube, read only): to check that a video landed on the right channel and to see its title, privacy and publish time.
  • Read my channel's numbers (YouTube Analytics, read only): views, watch time, how much of each video people watched, traffic sources and viewer countries, so I can see which videos work.
  • Captions, only if I switch it on: to attach the subtitle file I made to my own video.

What it does with that data

It uses it only to do the jobs above for my own channels. It does not sell it, rent it, share it, show ads with it, or use it to train any AI model. It does not read anyone else's channel, comments or private information.

Where it is kept

The sign-in key Google gives the program is saved in a private folder on my own computer and nowhere else. The numbers it reads are saved as small report files on the same computer so I can compare weeks. Nothing is sent to any server of mine, because there isn't one.

Google's rules

My Automation Agent's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services, so the YouTube Terms of Service and the Google Privacy Policy apply.

Removing access

Access can be taken back at any time from the Google account's third-party connections page. Once that is done the program can no longer upload or read anything, and I delete the saved sign-in key from my computer.

Changes

If the program ever starts using a Google account in a new way, I will update this page and the date at the top first.
